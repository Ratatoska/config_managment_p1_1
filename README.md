# Эмулятор командной строки

**Вариант 8 · Комаров В.Ю. · ИКБО-41-25**

Практическая работа № 1 по конфигурационному управлению.
Графический терминал на Python и Tkinter.

## Что сделано — этапы 1–4

- Окно с именем VFS в заголовке.
- Парсер с поддержкой одинарных и двойных кавычек.
- `ls` и `cd` работают с VFS; заглушки доступны в коммитах этапов 1–3.
- `exit` завершает сеанс.
- Ошибки команд и кавычек выводятся в терминал.
- Пути к VFS и стартовому скрипту задаются при запуске.
- Все параметры выводятся при старте.
- Стартовый скрипт показывает ввод и вывод и пропускает ошибки.
- Для OS-скриптов и проверок доступен режим `--headless`.
- VFS загружается из JSON целиком в память; файлы содержат base64.
- Проверяются структура, права, корень и родительские каталоги.
- Реализованы `find`, `cal` и `who`.

## Запуск

Нужен Python 3.10 или новее с Tkinter. Сборка не требуется.
Внешние библиотеки не используются.

```bash
python src/main.py
python src/main.py examples/vfs.json examples/startup_stage2.txt
python src/main.py examples/vfs.json examples/startup_stage2.txt --headless
```

Linux и Git Bash: `bash run.sh`. Windows: `run.bat`.
По умолчанию загружается учебная VFS `examples/vfs.json`.

## Параметры

```text
main.py [путь_VFS] [путь_стартового_скрипта] [--headless]
```

По умолчанию путь VFS — `examples/vfs.json` внутри проекта.
Сценарий необязателен; в GUI команды вводятся вручную, а `--headless`
читает stdin. Строки, начинающиеся с `#`, и пустые строки пропускаются.
`exit` прекращает выполнение сценария и закрывает GUI.

## Формат JSON VFS

```json
{
  "name": "my-vfs",
  "entries": [
    {"path": "/", "type": "dir", "mode": "755"},
    {"path": "/hello.txt", "type": "file", "content": "SGVsbG8hCg=="}
  ]
}
```

`name` — имя в заголовке окна, `entries` — список узлов.
`path` — нормализованный абсолютный UNIX-путь, `type` — `dir` или
`file`, `content` — base64, `mode` — восьмеричные права от 000 до 777.
У каталогов нет содержимого; все родители должны присутствовать.
Необязательный `owner` по умолчанию равен текущему пользователю ОС.
Никакие виртуальные файлы не распаковываются на диск.

## Интерактивная демонстрация

Введите в окне:

```text
ls -la
cd "my folder"
find / -name "*.txt" -type f
cal 10 2026
who
unknown
ls "broken
exit now
exit
```

Команды показывают результат; ошибки не закрывают окно.
После `exit` окно закрывается.

## Основные команды

| Команда | Режимы и назначение |
| --- | --- |
| `ls [-a] [-l] [путь]` | Содержимое каталога или имя файла; `-a` добавляет скрытые элементы, `-l` показывает права, владельца и размер. Флаги можно объединять. |
| `cd [путь]` | Переход по VFS; без аргумента — корень. Поддерживаются `..`, `~` и `cd -`. |
| `find [путь] [-name маска] [-type f\|d]` | Рекурсивный поиск в VFS. Выводит абсолютные пути. |
| `cal [год]` или `cal [месяц год]` | Без аргументов — текущий месяц; год — весь год; месяц и год — заданный месяц. Неделя начинается с понедельника. |
| `who` | Учётная запись и имя узла реальной ОС для текущего сеанса эмулятора. |
| `exit` | Завершение сценария и закрытие окна. |

`ls` принимает один путь; неподдерживаемые флаги считаются ошибками.
VFS не содержит символических ссылок. Конвейеры, перенаправления
и запуск внешних программ не входят в язык эмулятора.
